# The Vault

Personal media catalog — browse, filter, and search 3,300+ movies, TV shows, documentaries, and standup specials. Track watched status and want-to-watch. Claude AI recommendations and "Surprise Me" available locally.

Deployed: [punkrockprogramming.github.io/the-vault](https://punkrockprogramming.github.io/the-vault/)

## Running

Open `index.html` directly in a browser. No server, no build, no install step.

AI features (recommendations, RIYL) are only active when running locally (`localhost` or `file://`).

## Files

| File | Purpose |
|---|---|
| `index.html` | All markup and CSS |
| `library.js` | `RAW` — the full catalog, organized by category |
| `metadata.js` | `METADATA` — genre tags, descriptions, poster paths (generated by `enrich.mjs`) |
| `app.js` | All application logic — filtering, rendering, search, AI, persistence |
| `enrich.mjs` | One-time enrichment script — calls TMDB/RAWG APIs to populate `metadata.js` |
| `wiz-watched.js` | `WIZ_FILMS` — wiz watch log overlay, regenerated by wiz-dashboard on startup (gitignored, local only) |

## Features

- Filter by genre, type (movie/TV/doc/standup), decade, mood
- Grid and list view, multiple sort modes
- Mark titles watched / want-to-watch (persisted in `localStorage`)
- `wiz watch` badging — films logged via `wiz watch` show 💀 ratings on their cards, count as watched, and get a WIZ LOG section in the detail modal (reaction + notes). Matched by slugified title; data flows from `~/.wiz-films/` via `wiz dashboard` startup. Local only — the deployed site 404s the overlay script harmlessly.
- "Surprise Me" — random pick from the unwatched list
- RIYL search — find similar titles by keyword
- Claude AI chat for recommendations (local only, uses `ANTHROPIC_API_KEY`)

## Deployment

Part of the `punkrockprogramming` monorepo, deployed as a standalone static site via git subtree:

```bash
git subtree push --prefix=the-vault the-vault main
```
